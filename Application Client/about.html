01

Керування записами

Створення, перегляд, редагування та видалення відправлень.

02

Параметри посилки

Тип доставки, вага, габарити, оголошена цінність і вартість.

03

Інтеграція з API

Дані завантажуються та зберігаються через REST API PostService.
